Each branch contains a different sim

<br>

**gravity** - a simple dynamics simulation with point particles, implements a gravity-like force as a demo but tweaked to be cooler

**ucm** - a demo of uniform circular motion using the dynamics sim

**collisions** - simulated collisions using impulse and momentum

**verlet_integration** - an implementation of verlet integration, which gives less error than the Euler-based approach used prior

**fixed_timestep** - implementation of a fixed timestep for a more consistent simulation

**rigid_body** - rigid body dynamics simulation with torque
